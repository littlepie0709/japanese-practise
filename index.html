Japonská slova: hiragana; přejatá slova a cizí jména: katakana.

Vyber gramatické téma

Plánované učení: nejdřív splatné kartičky, potom nové. Limit platí napříč skupinami, pro každý směr zvlášť. Režim Všechny limit obchází.

Chybné znaky dostaneš v tomto kole ještě jednou. Režim podobných znaků používá vybranou skupinu místo řádků.

Vyber řádky k procvičování

V tomto režimu zůstávají znaky vždy japonsky, i když zapneš český přepis. Výběr lekce se nepoužívá. は = ha, へ = he; jako částice se čtou wa a e.

Malý tahák k lekcím 1–3

1 · Představení: A は B です = A je B. は se čte „wa“. Otázka končí か. A の B vyjadřuje vlastnictví nebo vztah. さん nepřidávej ke svému jménu.

2 · Nakupování: これ stojí samostatně; この potřebuje podstatné jméno. ここ / そこ / あそこ = tady / tam u tebe / támhle. も = také, じゃないです = není.

3 · Činnosti: を = předmět, で = místo činnosti, に / へ = cíl pohybu, に = konkrétní čas. あした a まいにち běžně bez časového に. Sloveso stojí na konci.

Slovesa: たべる → たべます; のむ → のみます; かえる → かえります; する → します; くる → きます. Zápor: ～ません. Pozvání: ～ませんか.

Čas: よじ = 4:00; しちじ = 7:00; くじ = 9:00; さんじはん = 3:30 (půl čtvrté). はたち = 20 let.

Četnost: よく = často, ときどき = občas; あまり a ぜんぜん se v těchto cvičeních pojí se záporem.
